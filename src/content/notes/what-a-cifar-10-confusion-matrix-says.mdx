The real CIFAR-10 confusion matrix has not been exported from evaluation, so this document does not simulate one. The portfolio deliberately omits that figure until the saved model produces a 10×10 matrix and downsampled training curves.

## Data needed before publication

- A 10×10 number matrix from the saved-model evaluation.
- Class labels in the same order as the matrix axes.
- At most 48 aligned epoch, training-loss, and validation-accuracy values.

When those artifacts exist, the inline SVG figure system will render them without a visual rewrite.
